Image decode-speed test

Times img.decode() on detached Image objects, one fresh object URL per measurement. Runs entirely offline from file://.

Before you start

  • Plug the laptop in and set the operating system's power mode to best performance (or the nearest equivalent).
  • Close all other apps and browser tabs. Keep this tab in the foreground.
  • Do not touch the machine (mouse, keyboard, other windows) during the run.
